En el presente informe se determinó el voltaje y resistencia equivalente de thevenin
de un circuito desconocido, con el fin de verificar el teorema de Thevenin y analizar
cómo la interacción externa de un circuito brinda información del mismo. Para ello,
se hicieron tres configuraciones distintas utilizando una resistencia variable, un
voltímetro y un amperímetro. Después, se aumentó la resistencia variable y se registró
el voltaje y la corriente asociada entre sus dos terminales. Se determinó el voltaje
y resistencia equivalente del circuito como $V_\mathrm{eq}=12,000\pm0,001\unit{\volt}$
y $R_\mathrm{eq}=1000,0\pm0,3\unit{\ohm}$, lo cuál concuerda con sus respectivos valores
nominales.
